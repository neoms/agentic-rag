# 云计算服务模型

## 云计算概述

云计算（Cloud Computing）是一种通过互联网按需提供计算资源的模式，包括服务器、存储、数据库、网络、软件和分析服务。用户只需为实际使用的资源付费，无需前期大量硬件投资。

云计算的主要优势包括：弹性伸缩（根据需求自动增减资源）、按需付费（Pay-as-you-go）、全球部署能力和高可用性。

## 三种服务模型

云计算服务通常分为三个层次：

**基础设施即服务（IaaS）**：提供虚拟化的计算资源，如虚拟机、存储和网络。用户负责操作系统和应用的安装与维护，云服务商负责物理基础设施。代表服务包括 AWS EC2、阿里云 ECS 和 Google Compute Engine。

**平台即服务（PaaS）**：提供应用开发和部署的完整平台，包括操作系统、中间件和运行时环境。用户只需关注应用代码，无需管理底层基础设施。代表服务包括 Google App Engine、Heroku 和阿里云弹性 Web 托管。

**软件即服务（SaaS）**：提供完整的、可直接使用的软件应用。用户通过浏览器或客户端访问，无需安装和维护。代表服务包括 Google Workspace、钉钉和 Salesforce。

## 部署模型

云计算的部署模型包括：

- **公有云**：由第三方云服务商拥有和运营，通过互联网向公众提供服务
- **私有云**：专为单一组织建设和运营的云基础设施
- **混合云**：结合公有云和私有云，允许数据和应用程序在两者之间共享
- **多云**：使用多个不同云服务商的组合方案，避免供应商锁定

## 容器化与编排

Docker 容器技术将应用及其依赖打包为轻量级的可移植容器，解决了"在我的机器上能运行"的问题。Kubernetes（K8s）是目前最流行的容器编排平台，提供自动部署、弹性伸缩和容器管理功能。K8s 的核心概念包括 Pod、Service、Deployment 和 Namespace。

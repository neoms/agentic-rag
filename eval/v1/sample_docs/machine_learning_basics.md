# 机器学习基础概念

## 什么是机器学习

机器学习（Machine Learning）是人工智能的一个子领域，它使计算机系统能够从数据中自动学习和改进，而无需明确的编程指令。Arthur Samuel 在 1959 年首次提出了这个术语，将其定义为"使计算机能够在没有明确编程的情况下学习的研究领域"。

## 三大学习范式

机器学习主要分为三种范式：

**监督学习（Supervised Learning）**：使用带标签的训练数据来学习输入到输出的映射关系。常见算法包括线性回归、逻辑回归、支持向量机（SVM）、决策树和随机森林。应用场景包括图像分类、垃圾邮件检测和房价预测。

**无监督学习（Unsupervised Learning）**：使用无标签的数据来发现隐藏的模式或结构。主要包括聚类算法（如 K-Means、DBSCAN）和降维算法（如 PCA、t-SNE）。常见应用包括客户分群、异常检测和特征压缩。

**强化学习（Reinforcement Learning）**：智能体（Agent）通过与环境交互，根据奖励信号来学习最优策略。Q-Learning 和 Deep Q-Network（DQN）是经典的强化学习算法。AlphaGo 和自动驾驶是其典型应用。

## 深度学习

深度学习（Deep Learning）是机器学习的一个子集，使用多层人工神经网络来学习数据的层次化表示。卷积神经网络（CNN）特别适合处理图像数据，通过卷积层、池化层和全连接层的堆叠来提取空间特征。

循环神经网络（RNN）及其变体 LSTM（长短期记忆网络）和 GRU 适合处理序列数据，如文本和时间序列。2017 年提出的 Transformer 架构彻底改变了自然语言处理领域，BERT 和 GPT 系列模型都基于此架构。

## 模型评估指标

机器学习模型的评估需要合适的指标。分类任务常用指标包括：准确率（Accuracy）、精确率（Precision）、召回率（Recall）和 F1 分数。回归任务常用均方误差（MSE）和 R² 分数。模型选择时，通常使用交叉验证（Cross-Validation）来获得更稳定的性能评估。
